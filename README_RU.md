# Супер Александр — Android-проект

## Что уже работает в веб-версии
- Сенсорное управление и клавиатура.
- Прыжки, платформы, монеты, враги и два мира с боссами.
- Магазин трёх костюмов: два дополнительных костюма покупаются за собранные монеты.
- Копилка монет, открытые костюмы и лучший результат сохраняются в localStorage браузера/приложения.
- Музыка, пауза и перезапуск.

## Как собрать Android-приложение
Нужны Node.js LTS, Android Studio и Android SDK.

1. Распакуйте архив.
2. В терминале откройте папку проекта.
3. Выполните:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

4. В Android Studio дождитесь синхронизации Gradle.
5. Для теста подключите Android-телефон с включённой отладкой по USB и нажмите Run.
6. Для APK выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

APK в этом архиве не приложен: его нужно собрать в Android Studio на компьютере с установленным Android SDK.


## Сборка APK прямо с телефона через GitHub Actions

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** репозитория.
3. Выберите workflow **Build Super Alexander APK** и нажмите **Run workflow**.
4. Дождитесь зелёного статуса сборки.
5. Откройте завершённый запуск, найдите раздел **Artifacts** и скачайте `super-alexander-debug-apk`.
6. Распакуйте скачанный архив и установите `app-debug.apk` на Android.

Сборка выполняется на серверах GitHub; Android Studio на телефоне не нужна.
Для загрузки проекта и запуска сборки нужен аккаунт GitHub и подключение к интернету.
